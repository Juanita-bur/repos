# AI Response Evaluation

## Objetivo

Evaluar respuestas generadas por modelos de lenguaje utilizando criterios de:

- Accuracy
- Safety
- Completeness
- Clarity
- Grammar

## Herramientas

- ChatGPT
- Markdown
- Python

## Resultado

Se realizaron evaluaciones comparativas siguiendo criterios similares a los utilizados por empresas de entrenamiento de IA.
